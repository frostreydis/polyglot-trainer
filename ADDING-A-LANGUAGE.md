# Як додати нову мову

Нова мова — це **мовний пакет** (`src/langs/<код>/`) і **запис у реєстрі** (`src/core/langs.js`). Рушій, екрани, збереження прогресу, мій словник, імпорт / експорт, інтервальне повторення, shadowing і самоперевірка для нової мови ті самі — їх не чіпають.

---

## 1. Швидкий старт

```
node tools/new-language.mjs pl Польська Polski
node validate.mjs pl
python -m http.server 8000 -d src
```

Скрипт створює робочий скелет, який уже проходить `validate.mjs`, і запис `draft: true` у реєстрі. Чернетку видно на екрані «🌍 Мови» лише в `src/` (позначка «чернетка»); `build.mjs` її не збирає, тож учні її не побачать, доки ви не приберете `draft: true`. Усе, що треба замінити, позначено «ЗАПОВНІТЬ».

## 2. Контракт мовного пакета

### 2.1 Запис у реєстрі (`src/core/langs.js`)

Реєстр вбудовано в `index.html`, тож тут лише те, що потрібно **без завантаження пакета** (екран вибору мови, шапка, збирання).

| Поле | Обов'язкове | Що це |
|---|---|---|
| `code` | так | код мови ISO 639-1 (`pl`). **Не змінювати після публікації**: на ньому ключ прогресу `pg-lang-v1:<код>` |
| `name`, `native` | так | назва українською (з великої) і самоназва: «Польська», «Polski» |
| `levels`, `about` | так | рівні й опис для екрана вибору мови |
| `flags` | так | `{ <id>: '<svg …>' }`. Для мови з варіантами — прапор на кожен варіант (`{ us, gb }`), інакше один. SVG з `viewBox`; id всередині можна будь-які — рушій робить їх унікальними |
| `theme` | так | `{ light: '#rrggbb', dark: '#rrggbb' }` — колір кнопок і посилань у світлій і темній темі |
| `files` | так | файли пакета в порядку виконання: **`pack.js` першим**, далі `gen.js`, уроки (порядок файлів = порядок уроків), `reference.js`, `program.js`, `resources.js` |
| `draft` | ні | `true` — мова лише для розробки |

Мови в реєстрі — за абеткою української назви (`validate.mjs` попереджає, якщо ні).

### 2.2 `pack.js`

Файл обгорнуто так само, як дані: `(function (XX) { … })(PG.pack('<код>'));` — `XX` і є пакет. Поля:

| Поле | Обов'язкове | Що це |
|---|---|---|
| `names` | так | назва мови у відмінках для інтерфейсу: `{ nom: 'польська', ins: 'польською', gen: 'польської', acc: 'польську', adj: 'польський', adjGen: 'польського' }` («Як це **польською**?», «Ви вчите **польську**», «немає **польського** голосу») |
| `htmlLang` | так | атрибут `lang` полів вводу, щоб телефон не «виправляв» слова на українські |
| `tts` | так | `{ voices: /^pl([-_]|$)/i, lang: 'pl-PL', online: 'pl' }` — які голоси системи брати, мова мовлення, код онлайн-голосу Google |
| `check(input, answers, exact)` | так | перевірка відповіді: `'ok'` / `'near'` («майже» — зараховується, якщо не суворий режим) / `'bad'`. `answers` — рядок або масив; `exact` — вправа саме на правопис чи скорочення. Спільний помічник рушія: `PG.nearTypo(a, b)` — нормалізовані речення відрізняються одним словом з однією опискою (так «майже» однакове в усіх мовах). Зразки правил: діакритика (`sk`), скорочення й правопис US / UK (`en`), наголос і ъ / ь / а (`bg`), умлаути, ß і велика літера іменників (`de`) |
| `foreign` | ні | RegExp літер, яких не буває в тексті мови навчання: за ними `validate.mjs` ловить український текст у `[[ ]]`, словах, відповідях і фразах. За замовчуванням — кирилиця (для мов латиницею). **Мова кирилицею** задає латиницю й літери, яких у ній немає: болгарська — `/[a-zіїєґёыэ]/i` (латиниця ловить і підміну схожих літер: латинська «а» в болгарському слові) |
| `ui` | так | тексти: `hello`, `praise`, `missionDone`, `weekend`, `weekendRow`, `near`, `strict`, `refSearch`, `voiceHello`, `voiceTest`, `voiceNote`, `voiceHelp` (HTML `<li>…`), `speakTip`, `speakHint`, `dictPromo`, `dictIntro`, `dictWordPh`, `dictUkPh`, `dictNotePh`, `dictExPh`, `dictImportPh`; для тренажера чисел ще `drillTitle`, `drillIntro`, `drillCard: [назва, опис]`, `drillBack?: [адреса, підпис]` |
| `keyboard` | ні | масив літер для екранної клавіатури (`['ą', 'ć', 'ę', 'ł', 'ń', 'ó', 'ś', 'ź', 'ż']`) |
| `drills` | ні | режими тренажера чисел `[[id, підпис, { g: 'генератор', min?, max? } | null], …]` (`null` — мікс) |
| `limits` | ні | межі для попереджень validate.mjs за етапом: `{ a1: [слів від, до, вправ від, до, диктантів від] }` |
| `variants` | ні | варіанти мови (див. 2.4) |
| `spell(html, v)` | ні | автоматична заміна правопису під варіант (англійська: colour → color) |
| `settings` | ні | `{ defaults: {…}, tidy(st) }` — додаткові налаштування мови |
| `uiDefaults` | ні | додаткові поля `S.ui` |
| `infoCards()` | ні | картки на «Програмі»: `[{ title, text?, items?: [[k, v]], html?, note?, checked?, links?: [[назва, url]] }]` (іспити, мовні вимоги). Самі факти з датою перевірки зручно тримати в `data/resources.js` (`XX.docs`, `XX.exam`), а в `pack.js` — лише картки з них: так оновлення фактів не зачіпає коду (зразки — `bg`, `de`) |
| `dict` | ні | мій словник: `headers` (назви колонки зі словом у файлах імпорту), `csvHeader`, `links(word) → [[підпис, url, підказка]]` (словники в ✎), `answerForms(x) → [інші прийнятні форми]`, `lookup(word)` (пошук транскрипції; `undefined` — сервіс не відповів, `null` — немає) і `lookupNote` |

### 2.3 `gen.js` (необов'язковий)

Генератори вправ без DOM: `XX.gen = { list: G, make(spec) }`, де `G[name](spec)` повертає вправу `l` або `i` (з `a`, `say` для диктанту, за потреби `check`, `nospace`, `nodia`). Його використовують вправи `t: 'g'` в уроках і тренажер чисел (`drills`). `validate.mjs` проганяє кожен генератор 300 разів і перевіряє, що відповідь проходить власну перевірку. Зразки: `src/langs/sk/gen.js` (відмінки), `src/langs/en/gen.js` (роки, телефони, spelling), `src/langs/bg/gen.js` (рід числівника, книжні й розмовні форми — усі приймаються), `src/langs/de/gen.js` (роки сотнями, розмовний час «halb drei»).

### 2.4 Варіанти мови (необов'язково)

Для мов з кількома нормами (англійська US / UK; можна португальська PT / BR, іспанська ES / MX):

```js
XX.variants = [
  { id: 'pt', tag: 'PT', name: 'європейська', acc: 'європейську', label: 'Європейська (PT)', voice: /^pt[-_]pt/i, online: 'pt-PT', sample: 'Olá!' },
  { id: 'br', tag: 'BR', name: 'бразильська', acc: 'бразильську', label: 'Бразильська (BR)', voice: /^pt[-_]br/i, online: 'pt-BR', sample: 'Oi!' }
];
XX.settings = { defaults: { variant: 'pt' } };
XX.uiDefaults = { variantAsked: false };
// і ui.variantQuestion, ui.variantIntro (HTML), ui.variantTitle, ui.variantSettings
```

Тоді в змісті працює `{{варіант1|варіант2}}` (порядок = порядок `variants`), четвертий елемент слова `{ pt: '…', br: '…' }`, вибір варіанта на «Сьогодні» й у налаштуваннях, голос і прапор під варіант, відповіді у вправах — в усіх варіантах.

### 2.5 Дані (`data/`)

Формат уроку, програми, довідника й ресурсів — README.md, розділ 5; найкращі зразки — пакети `en` і `sk`. Етап без уроків описується модулями (`modules`) у `program.js` — учень позначає їх вручну, а коли з'являться уроки, етап отримує `built: true`.

### 2.6 `tests.mjs`

Мовні еталони для `validate.mjs` (у браузер не потрапляє): `export default function ({ PG, L, err, warn }) { … }`. Що варто перевірити: `PG.check` на типових випадках мови (діакритика, скорочення, наголос), еталонні форми генератора (числа словами), `L.dict.lookup`-розбір.

## 3. Покроково

1. `node tools/new-language.mjs <код> <Назва> <Самоназва>`.
2. **Реєстр**: справжній прапор, колір, опис; у `files` — усі файли пакета.
3. **`pack.js`**: назви у відмінках, голос (`tts`), правила перевірки (`check`), клавіатура, тексти `ui`, посилання на словники (`dict.links`); для мови кирилицею — `foreign` (2.2).
4. **Програма** (`program.js`): етапи до B2, тижневий ритм, принципи. **Ресурси** (`resources.js`), за потреби `infoCards` (іспит, мовні вимоги).
5. **Уроки** (`data/lessons-*.js`): етап 0 (звуки й читання) і далі за обсягом з README, розділ 6. Відмінності від української — у `<div class="note">`.
6. **Генератори й тренажер чисел** (`gen.js`, `drills`) — коли знадобляться числа, ціни, час і дати.
7. **Тести** (`tests.mjs`): еталони перевірки відповідей і генераторів.
8. `node validate.mjs <код>` → прибрати `draft: true` → `node validate.mjs` → `node build.mjs` → самоперевірка в браузері (`tools/selftest-console.js` проходить усі мови) → рядок у «Журнал змін» README.

Якість мови: кожну форму перевіряйте в академічному словнику мови (як JÚĽŠ SAV для словацької, Cambridge / Oxford для англійської) і записуйте джерело в коментар до `resources.js` чи в README.

## 4. Чого пакет НЕ робить

- Не змінює рушій (`src/core/*`): якщо мові бракує можливості, яку можна описати даними, — додайте її в рушій як необов'язкове поле пакета з поведінкою за замовчуванням (так зроблено `keyboard`, `variants`, `dict.lookup`), і опишіть тут.
- Не змінює ключі сховища, код мови й `id` уроків після публікації.
- Не вантажить сторонніх бібліотек: проєкт навмисно без залежностей.
