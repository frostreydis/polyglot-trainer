# Polyglot — тренажер мов (англійська, болгарська, німецька, словацька, …)

Усі правила роботи з цим проєктом — у README.md (структура, рушій і мовні пакети, формат уроків, робочий цикл агента, як додавати уроки й виправляти помилки), архітектура й варіанти — в ARCHITECTURE.md, нова мова — в ADDING-A-LANGUAGE.md:

@README.md

Коротко: редагуйте тільки `src/` (папка `docs/` — зібраний сайт для GitHub Pages, вона генерується); спільний рушій — `src/core/`, усе мовне — у пакеті `src/langs/<код>/`; після змін запускайте `node validate.mjs` і `node build.mjs`, нічого не встановлюйте; коди мов, ідентифікатори уроків і ключі сховища (`pg-app-v1`, `pg-lang-v1:<код>`) не перейменовуйте.
