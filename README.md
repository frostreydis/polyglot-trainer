# Polyglot — мови з нуля до B2 для україномовних

**Polyglot** — тренажер мов для україномовних, що працює в браузері як вебдодаток (PWA): сайт на GitHub Pages, прогрес — у localStorage браузера. Один інтерфейс для всіх мов: учень вибирає мову, а прогрес, налаштування й мій словник **кожної мови зберігаються окремо** — перемикатися можна будь-коли, нічого не губиться.

Зараз у тренажері чотири мови. Уроки, програми й довідники англійської та словацької перенесено з двох окремих тренажерів без змін змісту, болгарську й німецьку написано для Polyglot:

| Мова | Звідки | Що є |
|---|---|---|
| 🇺🇸🇬🇧 Англійська | [Hello, English](../english-trainer/README.md) | етап 0 + A1–B2: 55 уроків, 908 вправ, 1205 слів; американська чи британська на вибір; транскрипція й записи носіїв у словнику; тренажер чисел і spelling |
| 🇧🇬 Болгарська | нова | етап 0 + A1: 17 уроків, 281 вправа, 346 слів; план A2–B2; кирилиця з різницею від української, екранна клавіатура ъ і ѝ; тренажер чисел, цін в євро, часу й дат; документи й іспит у Болгарії |
| 🇩🇪 Німецька | нова | етап 0 + A1: 17 уроків, 291 вправа, 376 слів; план A2–B2; клавіатура ä ö ü ß; тренажер чисел, цін, років, офіційного й розмовного часу («halb drei») і дат; мовні вимоги Німеччини, Австрії, Швейцарії та іспити Goethe / telc / ÖSD / DTZ |
| 🇸🇰 Словацька | [Ahoj, Slovensko](../slovak-trainer/README.md) | етап 0 + A1: 19 уроків, 247 вправ, 348 слів; план A2–B2; клавіатура з діакритикою; тренажер чисел, цін, часу й дат; мовні вимоги для ВНЖ |

Нова мова додається **мовним пакетом** — папкою `src/langs/<код>/` і записом у реєстрі; рушій, екрани, збереження прогресу й словник для неї ті самі. Покроково — [ADDING-A-LANGUAGE.md](ADDING-A-LANGUAGE.md). Чому саме так і які були інші варіанти — [ARCHITECTURE.md](ARCHITECTURE.md).

Цей README написано і для людини, і для **агента (Claude Code тощо)**: тут є все, щоб доповнювати тренажер і виправляти помилки з іншої сесії.

## 1. Як користуватися

1. Відкрийте сайт у **Chrome** або **Edge** (адреса на GitHub Pages: `https://<нік>.github.io/polyglot/`, див. розділ 10) і **встановіть як додаток**: Android — меню ⋮ → «Додати на головний екран»; комп'ютер — значок «Установити» в адресному рядку; iPhone / iPad — «Поділитися» → «На екран „Додому“». Встановлений додаток працює без інтернету, а браузер надійніше зберігає його дані.
2. **Виберіть мову** на першому екрані. Змінити мову — натиснути прапор у шапці (або «змінити мову» на «Сьогодні», або ⚙️ «Налаштування» → «Мова навчання»). Екран «🌍 Мови» показує для кожної мови пройдені уроки, слова в пам'яті, серію днів і останнє заняття.
3. Далі все як у старих тренажерах: «Сьогодні» (план на день, поточний урок, таймер), «Програма», «Уроки», «Слова» (інтервальне повторення), «📒 Словник», «Розмова» (shadowing із записом голосу), «Довідник», «Налаштування».
4. **Варіант мови.** Для англійської тренажер питає «Яку англійську вчимо?» — американську (US) чи британську (UK). Від вибору залежать прапор, голос, правопис (`color` / `colour`), пари слів (`apartment` / `flat`) і транскрипція; відповіді у вправах зараховуються в обох варіантах. Змінити — в ⚙️ «Налаштування» чи перемикачем у словнику.
5. **Голос** — голос системи мови навчання (Edge: *Natural*-голоси; Chrome: *Google*; Mac / iPhone — завантажені голоси), а якщо його немає — онлайн-голос Google. Голосом іншої мови тренажер нічого не читає. Як додати голос — ⚙️ «Налаштування» → «Голос».

### 1.1 Прогрес

- Прогрес кожної мови — окремий запис у localStorage (`pg-lang-v1:<код>`), вибір мови — `pg-app-v1`. Скидання в ⚙️ «Налаштування» стосується лише поточної мови; мій словник ці кнопки не видаляють.
- Прогрес старих тренажерів «Hello, English» і «Ahoj, Slovensko» сюди не переноситься: у Polyglot кожна мова починається з нуля, а старі тренажери лишаються окремими сайтами зі своїм прогресом. Мій словник можна перенести файлом: експорт у старому тренажері → ⇅ «Імпорт» тут.

### 1.2 Мій словник

Для кожної мови свій: додати слово з перекладом, приміткою, прикладом і транскрипцією; послухати (🔊, 🐢, інший варіант мови); повторення разом зі словами уроків; тренування (диктант, переклад, вибір); **експорт та імпорт** (JSON з прогресом, CSV, таблиця в буфер, «Поділитися»; імпорт з файлу чи вставленого тексту, з переглядом, злиттям і скасуванням). Файл словника містить код мови; файл іншої мови можна імпортувати, але тренажер попередить.
Лише англійська вміє сама знаходити транскрипцію й записи носіїв (сервіс dictionaryapi.dev, отримує лише англійське слово). Посилання на словники в ✎ — свої для кожної мови (англійська — Cambridge і YouGlish; болгарська — Речник на българския език БАН, Словоред і Forvo; німецька — Duden, DWDS і Forvo; словацька — JÚĽŠ SAV і Forvo). Німецькі іменники записуйте з артиклем (`der Kassenbon`) — словники отримають слово без нього.

### 1.3 Як перевіряються відповіді

Правила — у мовному пакеті:
- **англійська**: регістр і розділові знаки не важливі; скорочення = повні форми (`I'm` = `I am`); британський і американський правопис однакові; одна описка в довгому слові — «🟡 Майже»;
- **болгарська**: регістр, розділові знаки й знак наголосу не важливі; ь чи а замість ъ (`сьм`), українські і / є, одна описка в довгому слові — «🟡 Майже»; у числах словами приймаються й книжні, й розмовні форми (`двадесет` / `двайсет`);
- **німецька**: розділові знаки й регістр першої літери не важливі; без умлаута чи з ae / oe / ue (`Maedchen`), ss замість ß, іменник з малої літери чи `sie` замість ввічливого `Sie`, одна описка — «🟡 Майже»;
- **словацька**: регістр і розділові знаки не важливі; без діакритики (`dakujem`) — «🟡 Майже»; у числах словами пробіли не важливі.
«Майже» зараховується, якщо в налаштуваннях мови не ввімкнено суворий режим.

## 2. Для кого (для рішень щодо змісту)

Україномовні (часто й з російською), самостійно, телефон і комп'ютер, **15–30 хв у робочі дні**, мета — **B2** без поспіху; пріоритет навичок: розмова → слухання → читання → письмо. Інтерфейс і пояснення — **українською**, приклади — мовою навчання. Тон дружній і короткий. Аудиторію й цілі кожної мови описано в `program.js` пакета, для англійської й словацької — ще й у README старих тренажерів (розділ 2).

Технології: чистий JavaScript без залежностей і фреймворків. Маршрутизація — `#/...`. Глобальний простір імен — `window.PG`; активна мова — `PG.L` (пакет), `PG.S` (її стан), `PG.code`. Сайт працює лише через `https://` або `http://127.0.0.1` / `localhost`: service worker, буфер обміну й мікрофон потребують безпечного контексту; `file://` не підтримується. Service worker реєструється лише в зібраній версії (`docs/`, де є `PG.BUILD`); у `src/` пакети вантажаться по файлах без кешу.

## 4. Робочий цикл агента (обов'язково)

1. **Редагуйте тільки `src/`** (і за потреби `tools/`, `build.mjs`, `validate.mjs`). `docs/` генерується, але її теж комітять: GitHub Pages віддає сайт саме з неї.
2. Після змін:
   ```
   node validate.mjs                          # усі мови
   node validate.mjs sk                       # лише словацька
   node validate.mjs en data/lessons-a2a.js   # з уроків англійської — лише цей файл
   node build.mjs                             # збирає docs/ і друкує версію збірки й розміри пакетів
   ```
   Для коду ще: `node --check src/<файл>.js`.
3. Перевірте в браузері: `python -m http.server 8000 -d docs` → `http://127.0.0.1:8000/`, F12 → Console, вставте вміст `tools/selftest-console.js`. Скрипт проходить **усі мови** (кожну — в кожному варіанті), усі екрани й усі вправи; очікуваний результат — «✅ Усе гаразд». Прогрес і словники на цій адресі він відновлює сам. Для розробки без кешу: `python -m http.server 8000 -d src`. Якщо зібрана версія показує старий вміст: F12 → Application → Service workers → Unregister.
4. **Нічого не встановлюйте** (npm-пакети, бібліотеки тощо): проєкт навмисно без залежностей. Потрібні лише `node` і за бажанням `python`.
5. Додайте рядок у «Журнал змін» унизу цього файлу.

## 5. Формат уроку (`src/langs/<код>/data/lessons-*.js`)

Файл даних обгортається функцією, яка отримує пакет мови; всередині — той самий формат, що й у старих тренажерах (там замість `L` було `EN` / `SK`, і саме ці імена лишилися у файлах — це параметр обгортки):

```js
(function (EN) {
EN.lessons = EN.lessons || [];
EN.lessons.push({
  id: 'a2-1',               // унікальний у межах мови, НЕ змінювати після публікації; починається з id етапу
  stage: 'a2',              // id етапу з program.js
  num: 'A2.1',              // номер для показу
  title: 'Past Continuous — що відбувалося в певний момент',
  dur: '2 тижні',
  goals: ['…', '…'],        // 2–4 пункти «після уроку я вмію…»
  theory: `HTML-рядок`,     // див. розмітку нижче
  vocab: [['word', 'переклад', 'примітка (необов\'язково)'], …],   // четвертий елемент — { us, gb } для мов із варіантами
  ex: [ …вправи… ],
  say: [['Phrase.', 'Переклад.'], …],     // фрази для shadowing (запис голосу)
  speak: ['Завдання для говоріння вголос', …],
  mission: 'Завдання в реальному житті'
});
})(PG.pack('en'));
```

Порядок файлів у `files` реєстру (`src/core/langs.js`) = порядок уроків. Зразки — `a1-1` в обох мовах.

### Розмітка в `theory`, `mission`, поясненнях `e`

- `[[текст]]` — клікабельний фрагмент мови навчання з озвученням; `[[показати|що озвучити]]` — якщо озвучувати треба інше. **Усередині `[[ ]]` — лише мова навчання** (кирилицю голос мови не прочитає; validate.mjs це перевіряє).
- `{{варіант1|варіант2}}` — лише для мов з варіантами (англійська: `{{US|UK}}`): показується варіант учня. `nv: true` у вправі чи розділі довідника, `<span class="nv">…</span>` у тексті — правопис не змінюється.
- HTML: `<h3>`, `<p>`, `<b>`, `<i>`, `<ul>`, таблиці в `<div class="tblwrap"><table>…</table></div>`; виноски `<div class="tip">`, `<div class="note">` (пастка, відмінність від української), `<div class="good">` (подібність з українською).
- Не вживайте рядок `</script`.

### Типи вправ (`ex`)

| `t` | Що це | Поля | Правила |
|---|---|---|---|
| `c` | вибір | `q`, `o: [правильний, хибний, …]`, `e?`, `exact?` | **`o[0]` — правильний** (порядок перемішується). Хибні варіанти — однозначно хибні; не мають збігатися з правильним після нормалізації мови (validate.mjs перевіряє), інакше `exact: true`. |
| `i` | введення | `q`, `a: 'відповідь'` або масив, `e?`, `exact?` | Нормалізацію (регістр, скорочення, діакритика) робить пакет мови — не дублюйте її в `a`, але додавайте інші природні варіанти. |
| `o` | порядок слів | `q` (переклад), `a: 'Sentence.'` або масив | Альтернативи — з тих самих слів (перевіряє validate.mjs). |
| `l` | диктант | `a: 'текст'`, `tr: 'переклад'` | 3–10 слів, озвучує голос мови. |
| `g` | генерована | `g: 'назва'`, `min?`, `max?` | `gen.js` пакета перетворює її на `l` або `i`. Генератори — у `G` у `gen.js` мови; режими тренажера чисел — `drills` у `pack.js`. |

Службові поля згенерованих вправ: `say`, `check(v)`, `nospace`, `nodia` (відповідь цифрами: цифрова клавіатура, без клавіатури літер), `ph`, `h`.

### Модель стану (localStorage)

```js
// pg-app-v1 — спільне для всіх мов
PG.A = { v: 1, lang: '<код мови>' | null, ui: { installTip } }
// pg-lang-v1:<код> — окремо для кожної мови
PG.S = {
  v: 1, start,
  settings: { voice, rate, strict, newPerDay, dir /* 'mix' | 'tl' (мова → укр.) | 'uk' */, …налаштування пакета (en: variant, autoIpa) },
  lessons: { '<id уроку>': { opened, theory, ex: { best, done }, speak, mission, skipped, run: { n, q, pos, ft, sk } } },
  modules: { '<id модуля>': true },               // ручні позначки етапів без уроків (словацька A2–B2)
  cards:   { '<lessonId|слово>': { due, int, ease, reps, lapses } },   // мій словник: 'my|слово'
  dict:    [{ word, uk, note?, ex?, ipa?, au?: { <варіант>: url }, added? }],
  days: { '<номер дня>': { ex, cards, speak } }, newDay: { day, count },
  ui:      { dictSort, …ui пакета (en: variantAsked) }
}
```

- Під час читання (`core.js` → `loadLang`) стан проходить `migrate` (`MIGRATIONS`), зливається з `defaults(pack)` і `tidy` (налаштування до відомих значень, словник через `PG.cleanWord`; адреси записів носіїв — лише з `api.dictionaryapi.dev`, `ssl.gstatic.com`, `upload.wikimedia.org`).
- Пошкоджений запис зберігається копією під ключем `pg-lang-v1:<код>-broken`, а мова стартує з чистого стану. Запис новішої версії (`v` > `LANG_VERSION`) не перезаписується, доки сторінку не оновлять.
- Інша вкладка змінила прогрес **цієї ж мови** — стан перечитується; вибір іншої мови в іншій вкладці цю вкладку не перемикає.

### Сумісність прогресу — важливо

- **Не перейменовуйте** `id` уроків і код мови: від них залежить прогрес. Ключі `pg-app-v1`, `pg-lang-v1:<код>` не змінюйте.
- Картка слова — `lessonId|слово` (мій словник — `my|слово`); слово з кількох уроків — одна картка з id першого уроку (`firstLesson`). Змінили `vocab[i][0]` — прогрес слова скинеться.
- Змінюєте формат стану мови — підніміть `LANG_VERSION` у `core.js` і додайте `MIGRATIONS[стара] = (s, pack) => { … }`. Нові поля зі значенням за замовчуванням міграції не потребують.
- Змінюєте формат файлу словника — підніміть `FORMAT_VERSION` у `dict.js` і зберігайте вміння читати старі файли.

## 6. Як додати чи переписати урок

1. Допишіть урок у файл етапу мови в форматі з розділу 5 (або створіть новий файл `src/langs/<код>/data/lessons-….js` і додайте його в `files` мови в `src/core/langs.js` — після інших `lessons-*` і **перед** `reference.js`).
2. Для етапу без уроків (словацька A2–B2): додайте `stage` уроку, а модулю в `program.js` — `lesson: '<id>'`; щойно в етапі з'являться уроки, поставте етапу `built: true`.
3. Обсяг, як у старих тренажерах: теорія з таблицями й озвученими прикладами, 15–25 слів, 12–18 вправ (мікс усіх типів, щонайменше 2 диктанти), 4–6 фраз для shadowing, 1–2 завдання для говоріння, 1 місія в реальному житті. Межі для попереджень — `limits` у `pack.js`.
4. `node validate.mjs <код> data/<файл>.js` → `node validate.mjs` → `node build.mjs` → самоперевірка в браузері.

Приклад запиту до агента: «Відкрий polyglot-trainer, прочитай README.md і додай словацький урок A2.1 за розділом 6».

## 7. Як додати мову

Коротко: `node tools/new-language.mjs pl Польська` створює заготовку `src/langs/pl/` і чернетковий запис у реєстрі; далі — `pack.js` (назви, голос, перевірка відповідей, тексти), `gen.js`, уроки, `tests.mjs`, прапор у реєстрі. Чернетка (`draft: true`) видна лише під час розробки в `src/`. Покроково, з повним описом контракту пакета — [ADDING-A-LANGUAGE.md](ADDING-A-LANGUAGE.md).

|---|---|
| Помилка в слові, перекладі, правилі | `src/langs/<код>/data/lessons-*.js`, `reference.js` |

| Не працює екран або кнопка | `views.js` / `views2.js` / `dictview.js`; помилка рендерингу — блок «Щось пішло не так» зі стеком |

| `validate.mjs` пише про болгарську «текст не мовою навчання» чи «чужі літери» | у `[[ ]]`, слові чи відповіді є латинська літера, схожа на кириличну (a / а, e / е, o / о, p / р, c / с), або українська і / є; перелік — `foreign` у `src/langs/bg/pack.js` |

Якість мови: англійську перевіряйте в Cambridge / Oxford Learner's Dictionaries і YouGlish, болгарську — у Речнику на българския език БАН (ibl.bas.bg/rbe) і правописному словнику (не беріть російських форм), німецьку — у Duden і DWDS, словацьку — у словниках JÚĽŠ SAV (не беріть чеських форм). ## 10. Публікація на GitHub Pages

1. Публічний репозиторій **`polyglot`**. Перед першим комітом — «Keep my email addresses private» і `git config user.email "<id>+<нік>@users.noreply.github.com"`.
2. Закомітьте все разом із `docs/`, гілка `main`. Settings → Pages → Deploy from a branch → `main` / `docs`.
3. Кожне оновлення: правки в `src/` → `node validate.mjs` → `node build.mjs` → самоперевірка → коміт `src/` **і** `docs/` → push.

Що варто знати:
- Сайти GitHub Pages одного акаунта мають **спільний localStorage**. Ключі й кеші Polyglot (`pg-…`, `pg-trainer-…`) не перетинаються зі старими тренажерами (`en-trainer-v1`, `sk-trainer-v1`, `en-trainer-…`, `sk-trainer-…`).
- Онлайн-голос — неофіційний сервіс Google (`translate_tts`), транскрипція — dictionaryapi.dev; обидва можуть змінитися чи зникнути, тоді працює голос системи. Їм надсилається лише текст мови навчання.
- Збірка видаляє з `docs/langs/` пакети зі старим відбитком — у коміті вони зникнуть разом із появою нових.
