# Архітектура Polyglot: як два тренажери стали одним

Документ для людини, яка вирішує, і для агента, який змінюватиме код: що було, які варіанти об'єднання розглядалися, що вибрано й чому, як влаштовано стан і чому прогрес старих тренажерів не переноситься.

---

## 1. Що було: аналіз двох тренажерів

`slovak-trainer` («Ahoj, Slovensko») і `english-trainer` («Hello, English») — **один рушій, скопійований і розвинений окремо**. Англійський — пізніший і повніший; словацький має кілька власних мовних рішень.

| | Словацький | Англійський |
|---|---|---|
| Простір імен / ключ сховища | `SK` / `sk-trainer-v1` | `EN` / `en-trainer-v1` |
| Зміст | етап 0 + A1: 19 уроків, 247 вправ, 348 слів; A2–B2 — лише план модулів | етап 0 + A1–B2: 55 уроків, 908 вправ, 1205 слів |
| Розмір зібраного `index.html` | 261 KB | 1 175 KB |
| Спільний код (≈80%) | стан і localStorage, міграції, синхронізація вкладок, постійне сховище, встановлення PWA, озвучення (голос системи + онлайн-голос Google), запис голосу, рушій вправ c / i / o / l / g, інтервальне повторення, пропуск / продовження / «почати з уроку», екрани, service worker, збірка, PNG-іконки з прапора, самоперевірка | те саме |
| Перевірка відповідей | норма + діакритика: без гачків — «майже» (`dia`); `nospace` для чисел словами | скорочення (`I'm` = `I am`), правопис US / UK, одна описка — «майже» (`near`), `exact` |
| Голос | лише `sk-*`, ніколи не читає іншим голосом | `en-*` з акцентом US / UK, сортування за якістю |
| Мовні особливості | екранна клавіатура á ä č ď…; «Мої слова» `custom: [{sk, uk}]` у вкладці «Слова»; генератори з відмінками («o piatej», «prvého mája»); картки ВНЖ та іспиту | варіанти US / UK: розмітка `{{US|UK}}`, автоматична заміна правопису, пари слів `{ us, gb }`; «📒 Мій словник» з транскрипцією, записами носіїв, імпортом / експортом; генератори роки, телефони, spelling |
| Ідентифікатор картки слова | `<урок>|слово` для кожного уроку окремо | `<перший урок зі словом>|слово` (одна картка на слово) |

Висновок: різниця зосереджена в **п'яти місцях** — перевірка відповідей, голос, клавіатура літер, генератори чисел і тексти інтерфейсу (назва мови у відмінках, привітання, підказки). Плюс дві «великі» мовні можливості: варіанти мови (англійська) і пошук транскрипції (англійська). Усе інше можна мати в одному примірнику.

## 2. Варіанти об'єднання

### Варіант A — «Лаунчер»: стартова сторінка з посиланнями на два старі сайти
- Нова сторінка з вибором мови веде на `/hello-english/` чи `/ahoj-slovensko/`.
- ➕ Майже нуль роботи, старий прогрес лишається на місці.
- ➖ Інтерфейс не єдиний (два додатки, два встановлення PWA, дві копії рушія); виправлення в рушії — двічі; нова мова = ще одна копія всього проєкту. **Не виконує вимогу «єдиний інтерфейс».**

### Варіант B — «Один бандл»: один рушій, усі мови в одному `index.html`
- Рушій узагальнюється, мови — дані в тому самому файлі; перемикач мови в шапці.
- ➕ Простий код завантаження, усе офлайн з першого відкриття.
- ➖ Кожна мова збільшує сторінку для всіх: уже зараз ≈1,4 MB HTML, з 5 мовами — 4–6 MB на телефоні, і весь цей JS розбирається при кожному запуску.

### Варіант C — «Рушій + мовні пакети» (ВИБРАНО)
- Один рушій (`src/core/`), кожна мова — **пакет** `src/langs/<код>/` з контрактом (`pack.js`: назви, голос, перевірка відповідей, тексти, генератори, словник) і даними уроків у старому форматі. Реєстр мов (`src/core/langs.js`) — назви, прапори, колір і список файлів.
- У зібраній версії рушій — `index.html` (≈200 KB), кожна мова — окремий файл `langs/<код>.<відбиток>.js`, що вантажиться, коли мову вибрано. Service worker кешує всі пакети, тож перемикання працює й офлайн.
- ➕ Єдиний інтерфейс; рушій один; нова мова не робить сторінку важчою; мовна логіка ізольована й тестується окремо (`tests.mjs`); зміст старих уроків перенесено **без змін** (змінилася лише обгортка файлу).
- ➖ Трохи складніше завантаження (асинхронний пакет, відбитки у назвах файлів) — це взяв на себе `build.mjs`.

### Варіант D — «Спільна бібліотека»: два репозиторії, рушій окремим пакетом (npm / git submodule)
- ➕ Кожна мова — свій сайт і свій реліз.
- ➖ Проєкт навмисно без залежностей і без npm; інтерфейс однаково не єдиний (два сайти); версіонування рушія між репозиторіями — зайвий процес для одного автора.

**Чому C:** це єдиний варіант, який дає і єдиний інтерфейс, і масштабування на нові мови без зростання сторінки, зберігаючи принципи старих тренажерів (без залежностей, без сервера, офлайн, GitHub Pages).

## 3. Стан і прогрес: варіанти й рішення

| Варіант | Як | Чому ні / так |
|---|---|---|
| Один ключ на все | `{ lang, langs: { en: {…}, sk: {…} } }` | Пошкодження, міграція чи переповнення одного запису зачіпає всі мови; дві вкладки з різними мовами затирали б одна одну |
| **Ключ на мову + ключ додатка** (вибрано) | `pg-app-v1` = `{ lang, ui }`; `pg-lang-v1:<код>` = стан мови в старому форматі | Кожна мова незалежна: своє скидання, свої міграції, своя копія `-broken`; синхронізація вкладок — лише для своєї мови; формат стану майже той самий, що в старих тренажерах, тож старий код екранів працює без переписування |
| Сервер / акаунти | — | Свідомо немає (як і в старих тренажерах) |

Що спільне для всіх мов: лише вибрана мова і позначка «порада встановити додаток прихована». Налаштування голосу, швидкості, суворості, напряму карток — для кожної мови свої (голос у кожної мови інший).

Мова вкладки живе в пам'яті вкладки: якщо в іншій вкладці вибрали іншу мову, ця вкладка її не міняє, але наступний запуск відкриє останню вибрану мову.

---

## 4. Прогрес старих тренажерів — свідомо не переноситься

Polyglot починає кожну мову з нуля: старі тренажери лишаються окремими сайтами зі своїм прогресом, і жодного коду, що читає їхні ключі (`sk-trainer-v1`, `en-trainer-v1`), немає. Ключі Polyglot (`pg-…`) від них відрізняються, бо сайти GitHub Pages одного акаунта мають спільне сховище. Мій словник переноситься файлом: імпорт упізнає поле зі словом і за назвою мови (`en`).

## 5. Мапа: старі файли → нові

| Старе | Нове |
|---|---|
| `src/core.js` (обидва) | `src/core/core.js` — спільне; англійський правопис і перевірка → `src/langs/en/pack.js`; словацька перевірка → `src/langs/sk/pack.js` |
| `src/exercises.js` | `src/core/exercises.js` (клавіатура літер — з `pack.keyboard`) |
| `src/dict.js`, `src/dictview.js` (en) | `src/core/dict.js`, `src/core/dictview.js` для всіх мов; dictionaryapi.dev → `pack.dict.lookup` англійської |
| «Мої слова» (sk, `views2.js`) | мій словник (`dictview.js`) |
| `src/views.js`, `src/views2.js` | `src/core/views.js`, `src/core/views2.js` — тексти мови з `pack.ui`, `pack.names`; новий екран «🌍 Мови» |
| `src/gen.js` | `src/langs/<код>/gen.js` (без змін) |
| `src/data/*.js` | `src/langs/<код>/data/*.js` (без змін змісту; `window.XX = …` → обгортка `(function (XX) {…})(PG.pack('<код>'))`) |
| прапор у `index.html` | `flags` у реєстрі `src/core/langs.js`; PNG-іконки — з нейтрального логотипа `#app-logo` |
| `validate.mjs` (обидва) | `validate.mjs` — загальні перевірки будь-якої мови + `src/langs/<код>/tests.mjs` |
| `tools/selftest-console.js` | проходить усі мови й усі варіанти |

## 6. Межі й ризики

- **Розмір пакета англійської** (≈1 MB) — як і раніше; завантажується лише тим, хто вчить англійську.
- **Мова кирилицею** (болгарська). Рушій не залежить від письма, але валідатор ловить український текст у `[[ ]]` і відповідях за «чужими» літерами — для латинських мов це кирилиця, для болгарської — латиниця й літери і, ї, є, ґ, ё, ы, э (`pack.foreign`). Короткий український текст без цих літер («так», «вона») валідатор від болгарського не відрізнить — тут допомагає лише вичитка.
- **localStorage ≈5 MB на сайт спільні для всіх мов** (і для старих тренажерів на тому самому акаунті). Типовий прогрес — десятки KB; ліміт словника — 20 000 слів на мову.
- **Онлайн-сервіси** (голос Google, dictionaryapi.dev) неофіційні чи безкоштовні — можуть змінитися; тоді працює голос системи.
